# ニャーちゃん おりょうりゲーム

白いネコの **ニャーちゃん** になって、いろいろなお料理を作り、妹の **ニューちゃん** に食べてもらう、小さなお子さま（7歳くらい）向けの無料のブラウザゲームです。（開発中）
[ニャーちゃん おせわゲーム](https://github.com/yoshiaki99/nya-chan_care_game) と同じキャラクター・設定で、おせわゲームから遊びに来て、ためたハートを持ちかえれるようにします。

- 失敗や罰はありません。どんなふうに作っても、ニューちゃんはよろこんで食べます
- ネコの体に悪いとされる食べもの（ねぎ類・チョコレート・ぶどう など）は出てきません
- 広告・課金・アクセス解析なし。個人情報は集めません（遊んだ記録は端末のブラウザの中だけに保存）
- 文字はひらがな・カタカナだけ。セリフはすべて読み上げます
- 一度ひらけば、インターネットにつながっていなくても遊べます

**遊ぶ**：https://yoshiaki99.github.io/nya-chan_cooking_game/ （公開の設定がすんだら、このアドレスで遊べます）

## 開発

仕様は [要件定義書_ニャーちゃんお料理ゲーム.md](要件定義書_ニャーちゃんお料理ゲーム.md) にまとめています。
土台のプログラム（画面の切りかえ・読み上げ・セーブ・オフライン・キャラクターの表示など）は、おせわゲームから複製しています。

### 手元で動かす

```sh
python3 -m http.server 8776
# ブラウザで http://localhost:8776 を開く
# おせわゲームから来たときの動き：http://localhost:8776/?from=osewa
```

### 公開

`main` ブランチに入ると、GitHub Actions（`.github/workflows/pages.yml`）が GitHub Pages に公開します。
はじめて公開する前に、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にしてください。

公開の手順の中で、次のことを自動でします。

1. `node tools/check_lines.js` … セリフが、すべて最後に「ニャー」で終わっているか・漢字が入っていないかを確かめる
2. `node tools/check_foods.js` … ネコの体に悪い食べものが、ざいりょう・レシピ・シール・セリフに出ていないかを確かめる
3. `node tools/check_svg.js` … ゲームの中で描く絵（SVG）が こわれていないかを確かめる
4. `python3 tools/build.py --out _site` … 最終更新の日時（`js/build_info.js`。最後のコミットの日時を日本時間で）を作り、オフライン用のファイル一覧（`sw.js`）を作りなおし、公開するファイルだけを `_site` にそろえる

`js/build_info.js` は、保護者メニューの「このゲームについて」に出す「最終更新」の日時です。`--out` のときだけ作り、リポジトリには入れません（`.gitignore`）。ふだんの `python3 tools/build.py` では `sw.js` の一覧にも入れません（コミットのたびに `sw.js` が変わらないように）。ビルドしていない開発用の版では「（開発用の版のため、ありません）」と出ます。

### おせわゲームと同じサイトに置くので

2つのゲームは `yoshiaki99.github.io` の下にあり、ブラウザからは同じサイトに見えます。保存の名前を分けています。

| | おせわゲーム | おりょうりゲーム |
|---|---|---|
| セーブデータ | `nya-osewa-v1` | `nya-ryouri-v1` |
| オフラインのキャッシュ | `nya-osewa-…` | `nya-ryouri-…` |
| ハートを わたす はこ | `nya-link-v1`（2つで つかう。料理ゲームが 入れて、おせわゲームが 受けとる） | |

### 道具（`tools/`）

| ファイル | すること |
|---|---|
| `build.py` | `sw.js` の一覧と、実際にある絵・声の一覧（`js/asset_list.js`）を作りなおす。**絵を足したり消したりしたら動かす**。`--out` のときは最終更新の日時（`js/build_info.js`）も作る |
| `check_lines.js` | セリフの決まり（最後に「ニャー」・1回だけ・漢字なし）を確かめる |
| `check_foods.js` | ネコの体に悪い食べもの（`js/recipes.js` の `G.NG_FOODS`）が出ていないかを確かめる |
| `check_svg.js` | ゲームの中で描く絵（SVG）に、同じ属性が2つないかを確かめる |
| `make_icons.py` | ホーム画面のアイコン（コックぼうしの ニャーちゃん）と共有用の絵を作る |
| `make_transparent.py` | 白い背景の線画を、背景透過の PNG にする |
| `make_poses.js` | ニャーちゃん・ニューちゃんの表情・動作の絵を、基準画から作る（Playwright が必要） |
| `make_voice.py` | セリフ・名前を声にする（`assets/voice/`・`js/voice_clips.js`）。APIキーは環境変数で渡し、リポジトリには入れない |
